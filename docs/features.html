Built for people who post the same thing, many times.

Each feature exists because a manual run through twenty groups goes wrong in the same few ways: wrong order, wrong message, forgotten group, forgotten time.

Message library

Import messages from a CSV exported from a sheet, or add them with New. Edit any message in place, or change the text for a single send without touching the saved copy.

Community picker

Lists every group your linked number is in. Search by name, tick the ones you want, or choose all. A filter can limit the list to one set of communities.

Sending order you control

Groups are listed and sent in the same order, sorted by the date in the group name, oldest first. The order you click the boxes does not change it.

WhatsApp-style preview

See the message in a chat window for each selected community: formatting, links, and the image above its caption.

Images

Attach a poster or a screenshot. The text goes out as the caption. Save an image with a message, or attach one for just this send.

Gentle sending

Waits a random 15 to 25 seconds between communities. You can change the range. An option swaps look-alike emojis and adds an invisible character so no two copies match.

Dry run

Run the whole send without posting anything. You see the order, the selection and the status of every group first.

Scheduling

Pick a date and time and the app sends then, while it is running and the computer is awake. A job that is more than 20 minutes late is marked missed and is never sent stale.

Live status and log

Every group shows queued, sending, sent or failed as it happens. A local log file records the exact text each group received.

Optional login

Set an environment variable for a password, and another for an email if you want one, and the app asks before it shows anything.

Local only

The server listens on your own machine. Nothing is sent anywhere except WhatsApp itself.
